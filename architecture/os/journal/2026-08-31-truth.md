## Corrections

- **`tee ... | head -N` nearly truncated a test run.** After the first full
  green `pnpm test:unit` run, tried to re-run it piped through `tee <log> |
  head -20` just to grab the seed line cheaply. `head` exits after 20 lines
  and closes its end of the pipe, which SIGPIPEs `tee`'s stdout and can kill
  the whole pipeline upstream — the log file ended up truncated at 20 lines,
  mid-test-run. Caught it by checking `wc -l` on the log afterward instead of
  trusting the truncated tail. Fixed by redirecting straight to a file with
  `> log 2>&1` (no pipe to anything that exits early) and reading the
  seed/summary from the complete file afterward. Re-ran fully; same result
  (373/3658/0-skipped), so nothing was lost, but this is worth remembering:
  never pipe a long-running command's only output through something that
  exits before the command naturally finishes.
- **What "last-truth-commit" means when history gets squashed by a ref
  reset.** Wanted a clean commit hash marking "where the previous truth
  cycle left off" for the step-7 diff. `git log -- STATE.md` and `git blame`
  on the whole file both point at a single commit, `3aaed896`, whose message
  is actually an *audit*-cycle commit ("01:04Z cycle... Also fixed local
  main: HEAD/local-main ref was stale... reset to origin/main") — that
  session's reset folded a large batch of prior history's file state into
  one commit from the audit cycle's perspective, not a genuine single
  giant commit of new work. Treated `3aaed896` as the correct anchor anyway:
  it is definitionally the parent of everything this cycle needs to diff
  (its content is byte-identical to what was actually on `origin/main` after
  the reset, and no commit between it and today's `HEAD` was hidden by the
  squash — `git log 3aaed896..HEAD` cleanly lists 49 ordinary commits). Noted
  here in case a future cycle sees the same "last-truth-commit is actually
  an audit commit" shape and wonders whether it's safe to diff from — it is,
  as long as `git log <that-hash>..HEAD` returns a plausible, gap-free commit
  count (it did: 49, matching normal multi-day cadence).
