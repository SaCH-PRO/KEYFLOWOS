# KEYFLOWOS Monorepo

## Overview
KEYFLOWOS is an AI-powered operating system designed to automate operations for service businesses, aiming for 80-90% automation. It provides pre-built Playbooks, a unified "Command" center with an AI-powered command bar, voice input, and integrated business intelligence. The system integrates six core engines: LaunchFlow, OperateAI, GrowthStack, ProfitLens, ScaleHub, and MasterClass Mode, offering a comprehensive solution for business automation, growth, and management. Its business vision is to provide a comprehensive, AI-driven platform for business automation, growth, and management, with a high degree of automation and pre-opinionated workflows.

## User Preferences
- Caribbean localization (TTD currency, Trinidad timezone)
- Refined dark theme with selective glassmorphism (Linear/Stripe/Notion-inspired)
- Event-driven architecture for automation
- Pre-opinionated flows (Playbooks)

## System Architecture
The project is a monorepo utilizing a Next.js 16 frontend (`apps/web`) and a NestJS backend API (`apps/server`), with PostgreSQL managed by Prisma. The backend uses SWC for transpilation, requiring explicit `@Inject(Token)` decorators for NestJS constructor injection.

**UI/UX Decisions:**
- Redesigned design system with a warm Caribbean color palette (orange `#F97316` primary, teal `#14B8A6` secondary), selective glassmorphism, clean elevation system, and PWA capabilities.
- All listing/grid views must be compact, minimizing vertical height and scrolling. Hover reveals additional info, click opens full detail interface.
- Standardized shared component library and consolidated shell design.
- Simplified "Today" surface with greeting header, cash flow forecast, priority queue, and collapsible AI briefing card.
- Tiered navigation with Primary Rail + Secondary Panel, featuring five master surfaces: Cockpit, Control Tower, Workspaces, Studio, and Public.

**Technical Implementations & Features:**
- **AI-Powered Automation:** Features a Business Autopilot System for archetype inference, revenue model detection, task orchestration, and legal/compliance. It includes a global AI entry point with route-aware context detection, chat drawer, and suggestion nudges. The AI Business Office Foundations layer implements an Intent → Plan → Execute → Log pipeline with a 4-tier governance engine and a comprehensive audit trail. An AI Copilot UX Shell provides a Global Copilot Panel (AI Command Center), module-contextual quick actions, and a Pro Auto Monitoring Engine that scans 10 health domains for actionable suggestions.
- **Global AI Command Layer (Phase 3):** The Copilot Panel is the sole AI interaction surface across all workspaces. Features: plan-first chat execution with structured plan steps (approve/reject per step), dynamic quick prompts generated from ProAutoInsights and business graph state (not hardcoded), unified cross-module Queue tab showing pending approvals + action queue items with module badges and priority sorting, Activity tab with per-action execution logs showing success/failure status and module context. Module AI hubs broadcast their context via `kf:module-context-update` CustomEvents consumed by the `AiContextProvider` (`apps/web/src/contexts/ai-context.tsx`), enabling the global command layer to be context-aware without direct coupling.
- **Business Intelligence Context System:** Gathers comprehensive business context from 16 guidance sub-profiles with a 5-tier weighted completeness system and a Business Builder intake wizard.
- **Control Tower Workspace (Universal Business Brain):** The default home surface, offering a centralized operational HQ with inline Command Entry, Business Health overview, actionable Daily Priorities, Risk Alerts, Pending Approvals queue, AI Daily Plan, Storefront Intelligence, Growth Operations panel, and a Module Health Grid.
- **Workspaces:**
    - **Revenue, Clients, Calendar, Content, Flows, Profile & Intelligence Workspaces:** Each offers specialized dashboards, metrics, and tools for their respective domains, often featuring AI-driven insights and streamlined workflows.
    - **Projects Workspace:** A delivery execution workspace with Kanban boards, list views, rich project cards, health scores, and a 10-tab project detail view integrating cross-module data connections (Client, Revenue, Calendar, Flows).
    - **Expenses Workspace:** Provides spending intelligence with transactions, budgets, categories, and insights. It includes KPI strips, inline categorization, period-over-period comparisons, margin analysis, vendor distribution, and AI cost-control guidance.
- **Core Business Functions:** Includes Billing & Payment (multi-method payments, subscription billing), User & Security (Multi-Tenant System, personalized authentication, granular per-module permission scopes, Team Activity Log), and a Financial Copilot Agent.
- **Communication & Content:** Features a Customer Notification System, Unified Composer & Distribution UX, Communications Delivery Engine with adapter-based architecture (Meta, Google, WhatsApp), WhatsApp Business Integration, and an Audience Health Dashboard.
- **Commerce & Fulfillment:** Offers a Public Storefront, Store Dashboard, Fulfillment Engine & Order Routing, Commerce Data Layer with new Prisma models for supplier architecture, and Commerce Intelligence & AI with a full commerce copilot layer for pricing, margin analysis, and inventory management. The Store workspace features a **Canonical Graph API** (`StoreReadinessService`) that provides server-side product-service mapping, drift detection, readiness scoring (launch/conversion/merchandising/promotion categories), and revenue snapshots. The frontend `use-store-data.ts` hook consumes graph data instead of client-side name matching. Overview Mode includes a Revenue Cockpit, readiness score rings, and CRM action buttons that trigger the global copilot. AI suggestions are dynamically driven by readiness data.
- **Autopilot Governed Delegation Engine:** 5 pre-built delegation loop templates (Payment Recovery, Lead Reactivation, Post-Purchase Follow-up, Booking Prep, Weekly Hygiene) with governance-aware execution via GovernanceService (respects tier-based approval/confirm/auto-execute policies), learning loop integration via AiMemoryService, 5-minute scheduler (includes momentum sweeps at 6AM per-business-timezone), and an Autopilot dashboard tab on the Autopilot page. Models: `DelegationLoop` + `DelegationLoopRun`. API: `/autopilot/businesses/:businessId/loops[/:loopId[/run|/runs]]`. MomentumSchedulerService has been folded into DelegationLoopService.
- **Guided Store Qualification Engine:** Transforms the public store into a guided qualification and conversion experience. Features: (1) Interactive guided package selector with multi-step questionnaire on public storefront, (2) Execution model tiers (DIY/AI-Assisted/Hybrid/Full-Service) on Products via `executionModel` + `executionMeta` fields, (3) AI quote-from-conversation endpoint that extracts needs/budget/objections from raw conversation text, (4) Asset intake + project kickoff flow post-package-selection, (5) Store workspace QualificationConfig UI with flow builder, intake checklist editor, and conversion funnel analytics, (6) QualificationJourney model tracking user progression through the funnel. Key files: `qualification.service.ts`, `guided-selector.tsx`, `asset-intake.tsx`, `qualification-config.tsx`. Config stored in `Business.metaData.qualificationFlow`.
- **Community Transactional Presence Network (Phase 1):** Transforms the community module into a business directory where every profile is a mini-storefront. Features: transactional presence fields on Business model (acceptingWork, currentCapacity, leadTime, preferredProjectTypes, budgetFit, positioningStatement), NetworkConnection model for follow/save relationships, directory search with multi-filter (industry, skills, capacity, budget, location), enhanced profile cards with capacity badges and offering previews, community profile pages with full transactional presence, and profile completeness incentives (13 checks including 3 transactional fields). Key files: `community.service.ts`, `community.controller.ts`, `directory.tsx`, `profile-card.tsx`, `community/profile/[businessId]/page.tsx`, `professional-profile-section.tsx`.
- **Multi-Model AI Gateway (Phase 7):** Infrastructure layer abstracting AI provider selection behind a unified routing layer. `ModelGatewayService` supports OpenAI, Anthropic, and xAI with task-based routing (7 task categories: extraction, classification, reasoning, content-generation, summarization, tool-calling, general), 3 AI modes (Balanced/Premium/Fast) each with distinct model selections per task, automatic fallback chains with retry logic, per-provider health tracking (latency, error rates, success counts), BYOK (Bring Your Own Key) support with AES-256-GCM encryption stored in AiMemory (null clears keys), and strict typed output contracts (`ai-output-contracts.ts`) that enforce failure on validation errors (triggering fallback). Data-driven routing config stored in DB (`AiMemory` at `__system__/settings/routing_table`) — loaded lazily and updatable via admin API without code changes. Observability fields on `AiUsageLog` track provider, latency, fallback usage, and error codes. **Streaming support:** `ModelGatewayService.streamComplete()` returns an `AsyncGenerator<StreamChunk>` for real-time token-by-token responses across all three providers (OpenAI, Anthropic, xAI). `FlowOrchestratorService.streamChat()` provides streaming with tool calling, governance checks, and follow-up summarization. SSE endpoint at `POST /ai/businesses/:businessId/flow/chat/stream` delivers chunks via Server-Sent Events. **Per-Provider Cost Budget Caps:** Businesses can set monthly cost budget caps (overall and per-provider: OpenAI, Anthropic, xAI) via the `budgetCaps` field in AI preferences. The gateway checks remaining budget before routing; providers over budget are automatically skipped in favor of cheaper alternatives. Budget status (spend, remaining, utilization %) is surfaced in the usage summary, provider stats, and a dedicated `GET ai/budget-status` endpoint. Near-limit warnings trigger at 85% utilization. New API endpoints: `GET/PUT ai/preferences` (mode, writing style, BYOK keys, budget caps), `GET ai/provider-health`, `GET ai/provider-stats`, `GET ai/budget-status`, `GET/PUT ai/routing-config` (super-admin only for updates).
- **AI-Powered Business Matching:** `BusinessMatchingService` in `apps/server/src/modules/ai/business-matching.service.ts` provides AI-powered business recommendations in the community directory. Uses hybrid approach: algorithmic scoring (skills overlap, industry match, location proximity, capacity, budget fit, project type compatibility) + AI-generated match explanations via `gpt-4o-mini`. Results cached in-memory with 30-min TTL for periodic re-computation. "Recommended for You" section shows at top of directory with match scores, type badges (Complementary Skills, Same Industry, Referral Partner, Collaboration), and explanations. API: `GET /businesses/:businessId/community/recommendations`. 1 AI credit per call.
- **Community Trust & Reputation Signals:** Adds trust signals and reputation scoring to community profiles. Features: Endorsement model (businesses can endorse connected businesses on specific skills), reputation score computed from profile completeness (25%), community activity (25%), connections (20%), endorsements (20%), and badges (10%). Six verified badges: Complete Profile (80%+ completeness), Active Store (has products/services), Community Contributor (5+ posts), Well Connected (5+ followers), Endorsed (3+ endorsements), Cohort Member (1+ cohorts). Trust signals displayed on profile cards (slide-over) and full profile pages with reputation meter, badge display, endorsement counts, and interactive skill endorsement. API endpoints: `GET /community/trust-signals/:businessId`, `GET /community/endorsements/:businessId`, `POST/DELETE /businesses/:businessId/community/endorsements`, `GET /businesses/:businessId/community/endorsements-given/:targetId`.
- **Strategic Intelligence & Forecasting:** Utilizes a StrategicIntelligenceService with 7 AI-powered engines for Revenue Forecasting, Profitability Analysis, Pricing Advice, Seasonal Pattern Detection, Opportunity Scanning, Risk Scanning, and Weekly Planning.
- **Platform Utilities:** Includes Cross-Module Intelligence Agents, Gamification, online store, public booking page, module event bus, keyboard shortcuts, webhook dispatcher, developer settings, Universal Export System, Business Documentation Engine, Navigation & Command System, and System Diagnostics & Health Center.
- **Workspace Compression & Naming:** "Flows" renamed to "Autopilot" across all UI surfaces (nav, breadcrumbs, command palette, copilot, health grid, profile). `WorkspaceInsightsPanel` → `GraphInsightsPanel` with 4-quadrant intelligence structure (What Matters Now / What's Next / AI Can Handle / Inaction Risk). `useWorkspaceIntelligence` → `useGraphIntelligence`. Old files kept as re-export shims. AutomationModule decoupled from CRM, Commerce, and Bookings modules (event-driven via AutomationExecutorService).
- **Design System Consistency:** Ensures unified error boundaries, standardized skeleton components, shared empty state and loading components, consistent typography, radius utilities, and card hierarchies.
- **Security:** Implements Error Boundaries for core modules and rate limiting for unauthenticated endpoints.
