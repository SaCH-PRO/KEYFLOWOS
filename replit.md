# KEYFLOWOS Monorepo

## Overview
KEYFLOWOS is an AI-powered operating system designed to automate operations for service businesses, aiming for 80-90% automation. It provides pre-built Playbooks and a unified "Command" center with an AI-powered command bar, voice input, and integrated business intelligence. The system integrates six core engines: LaunchFlow, OperateAI, GrowthStack, ProfitLens, ScaleHub, and MasterClass Mode, offering a comprehensive solution for business automation, growth, and management.

## User Preferences
- Caribbean localization (TTD currency, Trinidad timezone)
- Glassmorphism UI with dark theme
- Event-driven architecture for automation
- Pre-opinionated flows (Playbooks)

## System Architecture
The project is a monorepo utilizing a Next.js 16 frontend (`apps/web`) and a NestJS backend API (`apps/server`), with PostgreSQL managed by Prisma. The backend uses SWC for transpilation, requiring explicit `@Inject(Token)` decorators for NestJS constructor injection.

**UI/UX Decisions:**
- Custom design system with a warm Caribbean-inspired color palette, Glassmorphism elements, and a dark theme, including PWA capabilities and mobile-optimized navigation.
- Unified Design Language across all modules: TabNav with folder-tab styling, `useSwipeTabs` hook, `useKeyboardShortcuts`, framer-motion directional slide transitions, error boundaries, and bespoke skeleton loaders.
- Custom Glassmorphism ConfirmDialog and skeleton loading states.
- Consistent module patterns: PageHeader, TabNav, keyboard shortcuts (1-N for tabs, N=new, R=refresh, Escape=close), mobile swipe navigation, and EmptyState components.
- Pipeline Kanban Board View with HTML5 drag-and-drop and persistent view preferences.
- Enhanced database tables with column visibility, responsive auto-hiding, multi-word search, and "Saved Views".
- Product detail and form components emphasize inline editing, real-time previews, validation, and performance optimizations using `React.memo`, `useMemo`, and `useCallback`.
- Accessible design with ARIA compliance and graceful error handling.

**Technical Implementations & Features:**
- **AI-Powered Automation:** Business Autopilot System with archetype inference, revenue model detection, task orchestration, and a Legal & Compliance Module.
- **Command Center:** Unified page with AI command bar, voice input, AI chat, and business metrics.
- **Commerce Module (3 tabs: Products | Billing | Insights):** Re-architected with `CommerceService` (CRUD), `CommerceStatsService` (KPIs with caching), and `CommerceAiService` (revenue analysis, cash flow forecast, NL interpreter, NL search, product health scan, client payment intelligence, quote win analysis). Includes a unified currency system, recurring invoice scheduler, product import system (CSV & AI Vision), and a unified billing panel. Features shared `BillingCard` and `BillingDetailModal` components for quotes/invoices (identical design, color-coded: quotes=violet, invoices=cyan), with `BILLING_DOC_THEME` theming, `formatAmount()` currency helper, sorting, expanded search, VOID status, aging buckets, and a pluggable architecture using `CommerceSlots`. Billing tab includes action queues (PaymentFollowUpQueue, QuoteActionQueue, AiSmartReminders) for actionable billing tasks. Insights tab includes RevenueRecoveryPlanner for aged receivables analytics. Invoice/Quote Template System with 3 selectable templates (Classic, Modern, Minimal) using brand colors, available in `commerce/components/invoice-templates/`. Template preference stored on Business model (`invoiceTemplate` field) and configurable in Commerce > Billing > BillingSettingsPanel. Templates render on the public payment page (`/pay/[invoiceId]`). Invoice/quote creation uses `BillingFormModal` — a full-screen overlay with backdrop blur, framer-motion spring animation, collapsible sections (Details, Line Items, Tax & Discount, Notes), live total in footer, unsaved-changes confirm dialog, and color-coded by doc type. Template Studio (`TemplateCustomizer`) provides full-screen template preview with live branding customization (colors, business details), desktop/mobile/print view modes, template switching, color presets, and print-to-PDF support. Accessible from BillingDetailModal ("View as Customer" button with real document data) and BillingSettingsPanel ("Customize & Preview" button with sample data).
- **Commerce AI Intelligence Suite:** NL Search (translates natural language into product/invoice/quote filters), Product Health Scan (data quality audit with severity scoring), Client Payment Intelligence (reliability scores, lifetime value, payment patterns per contact), Quote Win Analysis (conversion funnels, win/loss patterns, improvement suggestions), Pricing Advisor, Revenue Analysis, Cash Flow Forecast, Invoice Reminder Drafter, and Pipeline Analysis. AI prompts in `commerce/prompts/` with Caribbean context (TTD, Trinidad). Commerce AI Search Bar (`commerce-ai-search.tsx`) supports dual-mode: NL search results and command execution. Commerce Tool Results Renderer (`commerce-tool-results.tsx`) provides structured UIs (progress rings, gauges, funnels) for all AI tool outputs.
- **Commerce Cross-Tab Interjectability:** Products → Create Quote/Invoice (prefilled with product line items). Quotes → Convert to Invoice with event emission. Invoices → View Contact (CRM navigation), AI Client Intel button. Billing Detail Modal → clickable product names linking back to Products tab, View Contact and AI Intel buttons for contacts. Module events: `commerce:quote_created`, `commerce:quote_converted`, `commerce:product_selected`, `commerce:view_client_intel`.
- **Commerce AI Quick Actions:** Product cards show AI sparkle button (pricing advisor) on hover. Products header has "AI Health Scan" button. Billing panel has "AI Recovery Plan" (overdue section) and "AI Forecast" (KPI area). BillingDetailModal has "AI Analyze" (client intelligence) and "AI Draft Reminder" (overdue invoices).
- **Commerce Event Bus Emissions:** Backend emits `product.created`, `product.updated`, `product.deactivated`, `quote.created`, `quote.sent`, `quote.converted`, `invoice.paid`, `invoice.sent`, `invoice.overdue` — all consumed by AutomationExecutor (Playbooks), WebhookDispatcher, GamificationListener, and AI wildcard listener.
- **CRM Module (4 tabs: Pipeline | Database | Insights | Engage):** Modular CRM with Contact Lists/Groups, Duplicate Detection, and AI copilot. Includes bulk edit, inline editing, import field mapping, virtual scrolling, and a pluggable notes and tasks system. Insights tab is contact-focused (lead scoring, engagement heatmap, conversion timeline, data quality) with a cross-link to Commerce Insights for financial analytics. Engage tab includes a BillingActivityCard showing overdue invoices and pending quotes with navigation to Commerce Billing.
- **Cross-Module Integration:** CRM Engage surfaces billing activity from Commerce (overdue invoices, pending quotes) without duplicating financial widgets. Commerce Billing consolidates all billing action queues formerly in a separate Engage tab. CRM Insights defers deep financial analytics to Commerce Insights via cross-link cards.
- **CRM AI Intelligence Suite:** AI Contact Summarizer, Smart Lead Scoring, AI Note Intelligence, Predictive Churn Detection, Natural Language CRM Search, Data Quality Scan, Duplicate Finder, Re-engagement Planner, and AI Follow-up Drafter.
- **Bookings Module (3 tabs: Calendar | Services | Insights):** Full CRM-standard patterns: TabNav, keyboard shortcuts (1-3 tabs, N=new booking, R=refresh, F=focus search, Shift+A=AI Hub, Escape=close), useSwipeTabs, framer-motion transitions, error boundary, PageHeader, bespoke skeleton. Calendar view with Month/Week/Day modes, status color coding (PENDING=amber, CONFIRMED=blue, COMPLETED=emerald, CANCELLED=red), search filtering, and today navigation. Services tab combines services management + staff panel. Insights tab with Recharts charts (booking volume, top services by revenue, peak hours heatmap, status breakdown donut, upcoming schedule). Cross-module events: `booking:cancelled`, `booking:view_contact` (→CRM), `booking:create_invoice` (→Commerce). AI Command Hub integrated.
- **Bookings AI Intelligence Suite:** NL Search (translates natural language into booking/service/staff filters), Schedule Optimizer (analyzes booking patterns, suggests optimal scheduling), No-Show Predictor (cancellation pattern analysis, risk scores), Revenue Insights (booking revenue analysis, peak hours, top services). Backend endpoints: `POST /bookings/businesses/:businessId/ai-search`, `ai-schedule-optimizer`, `ai-no-show-predictor`, `ai-revenue-insights`. AI Search Bar (`bookings-ai-search-bar.tsx`) with NL query support. Tool Results Renderer (`bookings-tool-results.tsx`) with structured UIs for all AI tool outputs.
- **Bookings Event Bus Emissions:** Backend emits `booking.created`, `booking.confirmed`, `booking.cancelled`, `booking.rescheduled`, `booking.completed` — consumed by AutomationExecutor, WebhookDispatcher, GamificationListener, and AI wildcard listener.
- **Marketing Module (3 tabs: Campaigns | Lead Forms | Insights):** Full CRM-standard patterns: TabNav, keyboard shortcuts (1-3 tabs, N=new campaign/form, R=refresh, F=focus search, Shift+A=AI Hub, Escape=close), useSwipeTabs, framer-motion transitions, error boundary, PageHeader, bespoke MarketingSkeleton. Modular architecture with `CampaignsPanel` and `LeadFormsPanel` extracted components. ConnectionBanner (Gmail) and ConnectionsSummary (social platforms). Insights tab with Recharts charts (campaign performance timeline, open/click rate comparison, form submission volume, top campaigns table, audience growth, status breakdown donut). Cross-module events: `marketing:campaign_created`, `marketing:campaign_sent`, `marketing:lead_captured`, `marketing:view_contact` (→CRM), `marketing:create_campaign_for_segment` (from CRM). AI Command Hub integrated.
- **Marketing AI Intelligence Suite:** NL Search (translates natural language into campaign/form filters), Campaign Content Generator (AI-written subject lines, body, CTAs), Campaign Performance Analyzer (open/click rate analysis, improvement suggestions), Audience Segment Advisor (CRM contact analysis for optimal targeting), Subject Line Optimizer (A/B variations with predicted performance), Lead Form Optimizer (conversion rate analysis, field optimization). Backend endpoints: `POST /marketing/businesses/:businessId/marketing/ai-search`, `ai-campaign-content`, `ai-performance`, `ai-audience`, `ai-subject-lines`, `ai-form-optimizer`. AI Search Bar (`marketing-ai-search-bar.tsx`) with dual-mode NL search and commands. Tool Results Renderer (`marketing-tool-results.tsx`) with structured UIs for all AI tool outputs.
- **Marketing AI Quick Actions:** Campaign cards show AI sparkle "AI Write" button on DRAFT campaigns. Form cards show "AI Optimize" sparkle button. Insights header has "AI Analyze" button for performance analysis.
- **Marketing Event Bus Emissions:** Backend emits `campaign.created`, `campaign.sent`, `lead_form.created`, `lead_form.submitted` — consumed by AutomationExecutor, WebhookDispatcher, GamificationListener, and AI wildcard listener.
- **Marketing Cross-Module Integration:** Lead form submissions auto-create CRM Contacts (source: LEAD_FORM, status: LEAD). Campaign recipients link to CRM contacts via "View Contact" navigation. CRM can trigger `marketing:create_campaign_for_segment` to pre-fill campaign audience. Campaign analytics integrate with Commerce for conversion tracking.
- **AI Command Hub System:** Unified AI access point per module with "Tools" (AI capabilities) and "Insights" (proactive AI suggestions).
- **Core Workflows:** Quote-to-Invoice workflow, multi-gateway payment system (WiPay, PayPal), subscription & billing, and expense tracking.
- **User & Security:** Multi-Tenant System with `businessId` isolation, personalized auth & onboarding (Google OAuth), and a notification system. CRM security includes input sanitization, DTO validation, rate limiting, and AI prompt injection guards.
- **Platform Features:** Gamification system, online store & public booking page, module event bus for cross-module communication, reusable keyboard shortcuts, and a webhook dispatcher system.
- **Observability:** Request correlation ID middleware, global logging interceptor, and health check endpoints.
- **Learn Module (MasterClass, 3 tabs: My Learning | Catalog | Certificates):** Componentized with course-card, course-catalog, learn-skeleton, lesson-viewer, and progress-tracker. Full CRM-standard patterns: TabNav, keyboard shortcuts, useSwipeTabs, framer-motion transitions, error boundary, PageHeader, bespoke skeletons.
- **Community Module (2 tabs: Feed | Cohorts):** Componentized with feed, post-card, create-post, cohort-list, and community-skeleton. Full CRM-standard patterns: TabNav, keyboard shortcuts, useSwipeTabs, framer-motion transitions, error boundary, PageHeader, post type filtering, cohort join/leave.
- **Error Boundaries:** All core modules have dedicated `error.tsx` boundaries (CRM, Commerce, Bookings, Expenses, Marketing, Projects, Reports, Learn, Community) providing graceful degradation with retry and dashboard navigation.
- **Core Modules:** Identity, CRM, Commerce, Marketplace, Bookings, Social, Projects & Playbooks, Flow, Reports, Command, Expenses, Webhooks, AI, Email Marketing, Lead Forms, Templates, Education, Community.
