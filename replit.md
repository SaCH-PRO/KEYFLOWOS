# KEYFLOWOS Monorepo

## Overview
KEYFLOWOS is an AI-powered operating system designed to automate operations for service businesses, aiming for 80-90% automation. It provides pre-built Playbooks and a unified "Command" center with an AI-powered command bar, voice input, and integrated business intelligence. The system integrates six core engines: LaunchFlow, OperateAI, GrowthStack, ProfitLens, ScaleHub, and MasterClass Mode, offering a comprehensive solution for business automation, growth, and management.

## User Preferences
- Caribbean localization (TTD currency, Trinidad timezone)
- Refined dark theme with selective glassmorphism (Linear/Stripe/Notion-inspired)
- Event-driven architecture for automation
- Pre-opinionated flows (Playbooks)

## System Architecture
The project is a monorepo utilizing a Next.js 16 frontend (`apps/web`) and a NestJS backend API (`apps/server`), with PostgreSQL managed by Prisma. The backend uses SWC for transpilation, requiring explicit `@Inject(Token)` decorators for NestJS constructor injection.

**UI/UX Decisions:**
- Redesigned design system with a warm Caribbean color palette (orange `#F97316` primary, teal `#14B8A6` secondary), selective glassmorphism, clean elevation system, and PWA capabilities.
- Compact UI elements, unified design language across modules, enhanced data tables with advanced features, and accessible design with ARIA compliance.
- Product detail and form components emphasize inline editing, real-time previews, validation, and performance.
- Standardized shared component library (`apps/web/src/components/ui/`): `StatusBadge`, `SideSheet`, `FilterBar`, `KfButton`, `DataTable`, `MetricCard`, `InspectorPanel`, `FeatureGuide`.
- Shell declutter: Momentum badge removed from global header; per-module AI search bars removed (CRM, Bookings, Marketing); custom getting-started guides replaced with shared `FeatureGuide` across CRM, Bookings, Marketing, Commerce, and Store modules.
- CSS type scale: `kf-text-micro` (10px), `kf-text-caption` (12px), `kf-text-body` (13px), `kf-text-emphasis` (14px), `kf-text-heading` (16px), `kf-text-title` (18px).
- CSS radius: `kf-radius-sm` (6px), `kf-radius-md` (8px), `kf-radius-lg` (12px).
- CSS card variants: `kf-card-metric`, `kf-card-action`, `kf-card-list-row`.

**Technical Implementations & Features:**
- **Onboarding Wizard:** Redesigned from chat-based concierge to 3-step visual wizard (`apps/web/src/app/app/onboarding/page.tsx`): Step 1 business type selection (6 industry cards), Step 2 first service/product creation with TTD-priced template defaults (inline editable), Step 3 publish & share (copy link, WhatsApp, social share). AI concierge chat preserved as optional "Need help?" slide-out drawer. Progress persisted via existing `fetchConciergeState`/`markConciergeComplete` APIs. Backend unchanged.
- **AI-Powered Automation:** Business Autopilot System for archetype inference, revenue model detection, task orchestration, and legal/compliance.
- **Command Center:** Decomposed daily operating dashboard (`apps/web/src/app/app/_command/`) with 7 focused modules: `use-command-data.ts` (data hook), `types.ts`, `quick-action-bar.tsx`, `ai-command-bar.tsx` (terminal-style AI input + chat drawer), `briefing-card.tsx` (collapsible AI briefing + financial pulse + campaign intelligence), `priority-queue.tsx` (unified Now/Today/This Week buckets merging priorities, tasks, momentum, nudges, alerts), and `simulation-drawer.tsx` (what-if simulator + cash flow forecast). Page shell is 118 lines.
- **Commerce Module:** Manages Quotes, Invoices, Schedules, and Insights. Features comprehensive CRUD, KPI tracking with caching, AI-powered revenue analysis, cash flow forecasting, NL interpretation, and a unified currency system. Supports recurring invoices, partial payments, and customizable invoice/quote templates via a `TemplateStudio`. Commerce Phase 2 introduced a 3-pane workbench layout (saved-views rail, center record list, right detail/inspector pane), right-sliding `SideSheet` builders replacing modals, context-driven smart CTAs per row (status-based primary action with overflow for secondary/destructive actions), 4 standardized card types (`ActionCard`, `MetricCard`, `RecordRowCard`, `InsightCard`), and decluttering rules (max 4 quick filters visible, max 1 primary CTA per zone, destructive actions in overflow only). Commerce Phase 4 (Innovation Layer) refactored the monolithic `useCommerce` hook into 5 focused hooks (`useCommerceShell`, `useBillingWorkspace`, `useCommerceOverview`, `useCommerceCopilot`, `useCommerceComposer`), added predictive AI capabilities (collections scoring, AI payment plans, smart quote follow-up, churn/risk alerts, revenue journey funnel analysis, reminder cadence orchestration), replaced persistent `FeatureGuide` with contextual onboarding (`SmartChecklist`, `SearchableHelpDrawer` via `?` shortcut), and added 7 innovation components wired into the Overview tab and AI Hub.
- **CRM Module:** Provides Contacts (pipeline, inline actions), Insights (analytics), and Studio (database/bulk ops). Features simplified contact cards, progressive disclosure of details, AI copilot for summarization, lead scoring, churn detection, and natural language search. Includes an AI-powered "Next Actions" service for prioritized recommendations.
- **Bookings Module:** Redesigned with 3 tabs: Schedule | Catalog & Capacity | Performance. Features a Today operating strip with 3 priority lanes (unconfirmed, no-show risk, overbooked staff), collapsible schedule filters (staff/service/status), side-sheet booking creation, booking-native service cards with active status, staff management, Availability & Hours section, Google Calendar integration (deep-links to Settings), and consolidated performance analytics with schedule health. Smart CTAs on all booking surfaces (day/week timelines, week calendar) with status-driven actions (Confirm, Check in, Invoice, Rebook). Uses CSS variable-based status styles (`STATUS_STYLE` in `bookings-types.ts`). Page shell ~150 lines.
- **Marketing Module:** Redesigned with 4 tabs: Create & Schedule | Calendar | Audiences & Forms | Performance. Create tab features a mode selector (Email Campaign / Social Post) with animated transitions between creation surfaces. Calendar tab shows unified content calendar with campaigns and social posts in month/week views with type filters and timezone-safe date handling. Audiences & Forms tab includes AudienceHealthSection for contact health scoring alongside lead form management with optimization queue. `/app/social` redirects to `/app/marketing?tab=create`. Legacy tab keys (`audiences`, `social`, `campaigns`, `forms`, `insights`) mapped to new keys. Removed redundant panels (MarketingLaunchpad, StrategyPanel, MarketingBriefPanel — consolidated into AI hub). Features `useMarketing` hook for state, `useMarketingAiHub` for AI suggestions, cross-module event listeners, post composer, and Lead-to-Revenue Funnel analytics. Page shell ~280 lines.
- **Client Momentum Agent:** Relationship intelligence system calculating per-contact momentum scores for prioritized action recommendations.
- **Campaign Intelligence Agent:** Provides post-campaign analysis, AI-powered performance briefings, pre-send validation with audience health scoring, and send-time optimization recommendations.
- **AI Command Hub System:** Unified AI access point per module with "Tools" (AI capabilities) and "Insights" (proactive AI suggestions).
- **Billing & Payment System:** Supports multi-method payments (WiPay, PayPal, Google Pay, bank transfer, cash) and features `PaymentLink` for shareable links, a public payment page, and redesigned payment settings. Manages subscription billing history.
- **Core Workflows:** Quote-to-Invoice, multi-gateway payment, subscription & billing, and expense tracking.
- **User & Security:** Multi-Tenant System with `businessId` isolation, personalized authentication (Google OAuth), notification system, input sanitization, DTO validation, rate limiting, and AI prompt injection guards.
- **Data Integrity:** Ensures atomic operations for campaign sending, lead form submissions, and valid tax/discount bounds.
- **Store Module:** Redesigned with 3 tabs: Storefront | Products & Hours | Performance. Storefront tab merges Settings + Customize + ReadinessChecklist (extracted standalone component) + MerchandisingPanel + SocialProofPanel + compact unpublished banner into cohesive setup surface. Products & Hours focuses on CatalogManager (with relative "last updated" timestamps) + HoursEditor. Performance tab uses inline Store Overview card (URL/status/share) + KPI grid + drifted items alert + ConversionInsightsPanel + StoreAnalyticsDashboard (no StoreCommandHero wrapper). AI Hub tab keys updated to valid tab keys (storefront/products/performance) with validation guard. Features Readiness Score, Conversion Insights, funnel visualization, and AI Command Hub (Store Optimizer, SEO Advisor, Pricing Advisor, Storefront Analyzer). Data hook extracted to `use-store-data.ts`. Page shell ~120 lines.
- **Expenses Module:** Decomposed from 812-line monolith into ~95-line shell + 11 focused sub-components (`apps/web/src/app/app/expenses/components/`): expense-filters, expense-stats, expense-list, expense-form-modal, expense-budgets-tab, expense-vendors-tab, expense-categories-tab, expense-analytics-tab, expense-detail-modal, expense-tax-calc, and shared use-expenses-data hook. 3-tab structure: **Expenses** (list + filters + tax estimator) | **Budgets** (budget tracking + categories) | **Analytics** (vendor analytics + spending trends).
- **Projects Module:** Decomposed from 1089-line monolith into ~85-line shell + 5 sub-components (`apps/web/src/app/app/projects/components/`): project-board (kanban), task-list (extracted task CRUD), playbook-panel, workflow-config, explainer-button. Clean 2-tab structure (Projects / Playbooks). Playbooks tab shows PlaybookPanel + "Automations" sub-section with cross-module WorkflowConfig.
- **Settings Consolidation:** Settings is the canonical location for all configuration. Duplicate settings surfaces in Commerce (billing settings panel, Gmail connect) and Bookings (calendar connect/disconnect) replaced with deep-link cards pointing to `/app/settings/connections` or `/app/settings/business`.
- **Cross-Module Contact Journey:** Enhanced `ContactJourneyTimeline` component (`apps/web/src/components/contacts/contact-journey-timeline.tsx`) provides unified lifecycle timeline in CRM contact detail "Journey" tab. Merges events, notes, tasks, invoices, and bookings into chronological entries with deduplication (event ID + title matching). Features module filter pills (All/CRM/Bookings/Commerce/Marketing), 4-stat summary strip (bookings count, paid revenue, last interaction, momentum score 0-100), date-grouped timeline with module-colored icons, and cross-module CTAs with deep-links to specific entities (View Invoice/Booking/Campaign).
- **Financial Copilot Agent:** Monitors revenue, expenses, and cash flow with anomaly detection, providing a Financial Pulse dashboard and weekly AI-powered briefings. Event-driven triggers for financial milestones and expense tracking.
- **Cross-Module Intelligence Agent:** An event-driven workflow engine that listens to key module events and triggers cross-module actions like CRM task creation, contact tagging, and notifications, configurable per business.
- **Platform Features:** Gamification system, online store & public booking page, module event bus for cross-module communication, reusable keyboard shortcuts, and a webhook dispatcher system.
- **Observability:** Request correlation ID middleware, global logging interceptor, and health check endpoints.
- **Learn Module:** MasterClass functionality with My Learning, Catalog, and Certificates.
- **Community Module:** Features Feed and Cohorts with social functionalities.
- **Error Boundaries:** Dedicated `error.tsx` boundaries for all core modules.
