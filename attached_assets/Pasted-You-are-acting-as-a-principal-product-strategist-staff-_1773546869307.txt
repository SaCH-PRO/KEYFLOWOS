================================
PHASE 2 — MASTER AUDIT
================================

Once classification is complete, perform a repo-aware full product audit.

Analyze the app through these lenses:

1. Product Architecture
- What kind of product architecture does the app currently have?
- Does it actually behave like one coherent business operating system?
- Are modules organized around user goals or internal object categories?
- Which modules are overgrown, under-defined, redundant, or mixed-purpose?
- Which responsibilities belong at module level versus platform level?

2. UX / UI Quality
- Is the app shell helping or creating clutter?
- Are there too many tabs, cards, menus, drawers, popups, banners, guides, and triggers?
- Is there a consistent interaction grammar?
- Does the app feel premium, modern, calm, and operationally efficient?
- Where does visual or behavioral fragmentation exist?

3. Workflow Efficiency
- Can users move smoothly across major journeys such as:
  - lead → contact → quote → booking → invoice → payment → follow-up
  - service setup → public booking/store → booking/invoice → customer communication
  - campaign/social lead → CRM → booking → revenue
- Where do handoffs feel broken, manual, or repetitive?
- Which module transitions should become more native and seamless?

4. Modularity / Plug-In Architecture
- Which entities should anchor the platform?
- Which components should be reusable across modules?
- Which cross-module contracts are missing?
- How should modules plug into each other without becoming tightly coupled?

5. Tiering / Progressive Disclosure
- What should beginner users see first?
- What should power users gain access to?
- What belongs in admin/studio/build mode?
- How can the app stay simple by default and powerful as users grow?

6. AI / Automation Readiness
- Does the current AI pattern reduce effort or add UI noise?
- How should command palette, module AI hubs, contextual AI, and proactive AI coexist?
- Which AI features should be visible versus embedded?
- Where should automation and event-driven workflows be first-class?

7. Competitive and Best-Practice Review
- Compare the product’s patterns to strong modern products in service-business operations, scheduling, CRM, billing, storefront, and marketing.
- Identify where the app is already differentiated.
- Identify where the app still feels fragmented, overbuilt, or immature.
