# KP-26: Attendee dashboard and check-in

## Milestone
Milestone 5: Events & Ticketing

## Labels
`keyportal`, `frontend`, `backend`, `events`, `checkin`

## Description
Give event owners visibility into registrations and a way to check in attendees.

## Acceptance Criteria
- [ ] Owner event detail page shows registrations tab.
- [ ] Registrations can be filtered by status/payment status.
- [ ] Owner can confirm/cancel a registration.
- [ ] Owner can check in attendee via `qrCodeToken` scan or manual entry.
- [ ] `/portal/ticket/[token]` displays ticket with QR code.
- [ ] CSV export of attendees available.
