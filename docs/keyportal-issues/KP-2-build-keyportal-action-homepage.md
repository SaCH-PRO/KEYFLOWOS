## Description

## Acceptance Criteria
- [ ] Business hero section displays logo, cover image, business name, tagline, and description.
- [ ] Action cards are visible for: Book, Order, Events, Promos, Contact.
- [ ] Each action card links to the appropriate sub-route or scrolls to section.
- [ ] Contact card uses business phone/email/WhatsApp when available.
- [ ] Mobile layout stacks cards cleanly.
- [ ] Design follows controlled customization guardrails (no custom CSS exposed).
- [ ] Uses data from existing public business lookup endpoint.
