## Milestone

## Description
Create public-facing event pages inside the portal.

## Acceptance Criteria
- [ ] `/portal/[slug]/events` lists published upcoming events.
- [ ] `/portal/[slug]/events/[eventSlug]` displays event details.
- [ ] Page shows ticket tiers with price, availability, sale window.
- [ ] Sold-out tiers are visually indicated.
- [ ] Event location/online URL displayed.
- [ ] Mobile responsive.
