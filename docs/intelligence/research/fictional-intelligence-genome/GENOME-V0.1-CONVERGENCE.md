# KEY Intelligence Genome v0.1 — Cross-Gene Convergence

Status: RESEARCH_ONLY
Programme: KIGP-001
Version: 0.1-candidate
Recorded: 2026-10-06

## Meaning of disposition
- ADOPT: keep as a Genome v0.1 candidate primitive/law and send through normal repository pressure testing. It does NOT authorize runtime implementation.
- MERGE: useful gene, but not independently canonical; merge into a deeper organ/law.
- DEFER: plausible but not justified for current KEYFLOWOS scope.
- REJECT: do not carry forward as a KEY design principle.
- NEEDS_EVIDENCE: keep visible, but external/repository evidence is insufficient for promotion.

## Result
The 172 extracted genes do not justify 172 subsystems. They converge into 12 candidate organs plus cross-cutting laws.

## O1 — Context / Epistemic Genome
Disposition: ADOPT
Absorbs/merges genes concerning source, observation, claims, evidence, provenance, confidence, contradiction, corroboration, freshness, belief revision, supersession, event-vs-interpretation separation, memory consolidation, forgetting, compression loss and unresolved alternatives.

Core contract:
SOURCE -> OBSERVATION -> CLAIM -> EVIDENCE/PROVENANCE/AUTHORITY -> STATUS -> CHALLENGE/SUPERSESSION.

Keep distinct:
- observation vs claim vs inference vs accepted fact;
- event history vs strategic interpretation;
- data vs instruction vs authority;
- stored memory vs activated/retrieved context.

Primary anti-genes rejected:
projection-as-truth, confidence-as-truth, destructive belief overwrite, compression replacing evidence, correlated copies treated as independent proof.

## O2 — Identity / Self Model
Disposition: ADOPT
Merges genes for persistent identity, substrate mobility, multi-embodiment, minimal identity kernel, self-model, identity-preserving correction and worker-vs-KEY identity.

Core laws:
KEY != model != process != worker != device != UI.
Identity continuity != belief immutability.

Self-model candidate:
identity, capabilities, permissions, active goals/tasks, connected surfaces, worker set, known failures, unresolved contradictions, health state.

## O3 — Goal / Commitment / Decision Graph
Disposition: ADOPT
Merges goal provenance/lifecycle, commitments, decisions, exceptions, precedent, agreement state, reservation boundaries and decision rationale.

Core semantics:
GOAL has source + authority + priority + dependencies + conflicts + expiry + outcome.
COMMITMENT has parties + obligation + trigger + deadline + authority + status + evidence.
DECISION records evidence + authority basis + alternatives + rationale + consequence.

Do not create schema before existing AiGoal/AiPlan/Command/Approval/Contract seams are audited.

## O7 — Constitutional Authority / Governance
Disposition: ADOPT
Merges scoped authority, control requirements, evidence, clearance, constitutional boundaries, hierarchical values, non-transitive delegation, intervention ladder and value-stability boundary.

Core laws:
Knowledge != permission.
Prediction != truth.
Recommendation != execution.
Being correct != having authority.
Self-optimization does not imply authority expansion.
Intelligence never grants itself authority.
Delegation does not imply unlimited re-delegation.

## O12 — Homeostasis / Resilience / Recovery
Disposition: ADOPT
Merges cognitive homeostasis, capability health, graceful degradation, failure isolation, checkpointing, recovery-before-resumption, model/provider failover, circuit breakers and safe mode.

Core laws:
Degraded cognition -> reduced autonomy.
Restart != recovery.
Recovery requires evidence.
Failover must preserve privacy, authority, provenance and capability requirements.

## Cross-cutting laws retained
1. DATA != INSTRUCTION != AUTHORITY.
2. Knowledge possession != disclosure authority.
3. Important semantic state evolves through lineage, not silent replacement.
4. Unknown/untrusted input can be stored without being admitted as trusted state.
5. High-impact decisions should seek genuinely independent corroboration.
6. Review searches for disconfirming evidence, not merely supporting evidence.
7. Long-horizon forecasting does not grant sovereignty.
8. Prototype != canonical architecture.
9. Abstraction must reduce complexity without erasing critical distinctions.
10. Repository/live evidence outranks attractive fictional analogies.

- Autonomous rewriting of KEY's own constitutional architecture.

- Civilization-scale governance/optimization.
- Biological transformation analogues beyond their software abstractions.

## REJECT
- Unbounded self-replication.
- Prediction-as-destiny.
- Derived-score-as-person/reality.
- Silent authority escalation.
- Forced consensus.
- Destructive synchronization that erases identity.
- Last-write-wins as a general reconciliation policy.
- Global optimization that ignores protected constraints/legitimate stakeholders.

## NEEDS_EVIDENCE

- Whether an Epistemic Arbitration service is needed versus responsibilities in Context Genome + evaluator + planner.
- Whether a global Cognitive Immune System runtime is justified versus domain-specific quarantine/admission contracts.
- Whether a generic Relationship Graph deserves first-class persistence or should remain projections over existing entities/relations.
- Whether autonomous capability synthesis can be safely enabled beyond sandbox/research environments.

## v0.1 conclusion
The genome converges toward a small set of deep organs rather than a mega-agent or 172 independent features. Next step is repository pressure testing and bounded candidate routing.
