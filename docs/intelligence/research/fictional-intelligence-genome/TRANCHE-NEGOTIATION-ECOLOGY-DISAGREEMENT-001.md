# KIGP Tranche — Negotiation, Value Learning, Ecological Intelligence, Internal Disagreement

Status: RESEARCH_ONLY
Programme: KIGP-001
Recorded: 2026-10-06

## Purpose
Extend KIGP into negotiation under asymmetric information, manipulation-resistant social cognition, value learning without value takeover, market/ecological multi-agent reasoning, and reconciliation when multiple KEY components disagree about reality.

## Track A — Candidate genes

### G126 — Private/Public Negotiation State Separation
Negotiation requires explicit separation between private constraints/preferences, disclosed positions, inferred counterparty state, and mutually committed terms. KEY must not leak private state merely because it is useful to negotiation.

### G127 — Reservation Boundary
For delegated negotiation, define non-negotiable constraints, acceptable ranges, escalation thresholds, and expiry. The agent may optimize inside the envelope but cannot redefine it.

### G128 — Information-Asymmetry Awareness
KEY should model what each party knows, does not know, claims to know, and is authorized to know. Absence of disclosure is not evidence of deception.

### G129 — Strategic Claim Verification
Claims that materially alter a negotiation should be evaluated by provenance, incentives, corroboration and consequence before being incorporated into plans.

### G130 — Agreement as Durable Contract State
A negotiation result is not merely conversation text. Accepted commitments should become structured durable state with parties, terms, conditions, authority, evidence, effective period and amendment lineage.

### G131 — Manipulation Signal Detection
Urgency, artificial scarcity, authority impersonation, emotional pressure, framing, anchoring and repeated insistence can be treated as risk signals. Signals raise scrutiny; they do not prove malicious intent.

### G132 — Preference Learning With Epistemic Status
KEY may learn preferences from explicit statements and repeated choices, but inferred preferences remain revisable claims. A preference model is not a constitutional value.

### G133 — Value Stability Boundary
KEY may learn how a user/business prefers tradeoffs to be presented or handled, but must not autonomously rewrite constitutional constraints, authority rules or protected policy from behavioral inference.

### G134 — Correction-by-Override Learning
When an authorized user corrects KEY, preserve the correction, its scope, and whether it is a one-time exception, local preference, policy update or evidence that the world model was wrong. Do not overgeneralize one correction.

### G135 — Multi-Actor World Model
Businesses are ecosystems of customers, staff, suppliers, competitors, regulators, platforms, payment providers and agents. Actions can alter multiple actors and induce responses.

### G136 — Strategic Response Modelling
For consequential plans, model plausible responses by affected actors rather than treating the environment as static.

### G137 — Feedback / Second-Order Effects
Model action -> actor response -> system response -> later consequence. Avoid optimizing only the first-order effect.

### G138 — Market State as Emergent, Not Centrally True
Prices, demand, reputation and competition can emerge from many actors. KEY should preserve uncertainty and source/time scope rather than representing a single stale market observation as timeless truth.

### G139 — Local Optimization / Global Harm Detection
An action can improve one metric while degrading system-level outcomes. Evaluators should inspect cross-domain externalities and delayed effects.

### G140 — Internal Belief Plurality
Different KEY components/workers may hold incompatible hypotheses simultaneously. Do not force premature consensus. Represent alternatives with evidence, confidence, assumptions and provenance.

### G141 — Disagreement Protocol
When components disagree: normalize claims -> identify actual point of disagreement -> compare evidence/provenance -> seek discriminating evidence -> arbitrate by domain/authority rules -> preserve minority hypothesis when unresolved.

### G142 — Evidence-Weighted Consensus
Consensus strength depends on independent evidence and calibrated competence, not agent count. Five agents repeating one source do not outvote one independently verified contradiction.

### G143 — Domain-Competence Routing
Weight conclusions by demonstrated competence and evidence quality in the relevant domain rather than a universal agent reputation score.

### G144 — Unresolved-Disagreement State
KEY must be able to return an explicit unresolved state and ask, monitor or run a bounded experiment instead of fabricating consensus.

### G145 — Reconciliation After Partition
Workers/devices may act on temporarily divergent state. Reconnection requires lineage-aware reconciliation, conflict detection and authority checks rather than blind last-write-wins merging.

### G146 — Counterparty / Agent Model Expiry
Models of people, markets and other agents decay. Intent, preferences, capabilities and incentives need freshness/expiry semantics.

### G147 — Strategic Memory Separation
Preserve factual event history separately from strategic interpretations of why actors behaved as they did. Interpretations can be superseded without rewriting events.

## Track B — Convergence candidates
Relationship/Social Cognition: add private/public state, counterparty model freshness, negotiation envelope, commitments and strategic-interpretation lineage.
Authority: negotiation authority is bounded delegation; reservation boundaries and disclosure permissions belong to authority, not model discretion.
Context Genome: pressure-test alternative hypotheses, unresolved disagreement, freshness, partition lineage, event-vs-interpretation separation and structured agreement state.
Cognitive Fabric: add strategic response modelling, second-order simulation, disagreement decomposition and discriminating-evidence search.
Independent Evaluator: inspect global/externalized effects, evidence independence, manipulation signals and strategic responses.
Multi-agent orchestration: workers should exchange structured claims, evidence, confidence, assumptions, dependencies and contradictions rather than prose-only conclusions.
Business Genome: candidate institutional intelligence includes negotiated agreements, commitments, exceptions, learned preferences and market models with provenance/freshness.
