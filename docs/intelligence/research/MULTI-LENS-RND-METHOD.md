# KEYFLOWOS Multi-Lens R&D Method

Status: ACTIVE RESEARCH METHOD

## Objective
Use external knowledge to improve KEYFLOWOS without replacing repository evidence, proliferating abstractions, or turning famous ideas into dogma.

## Standard transformation
chapter/section -> source claim -> durable principle -> modern evidence/counterevidence -> AI-agent equivalent -> current KEYFLOWOS capability -> gap -> anti-duplication check -> candidate change -> pressure test -> adopt/reject/defer.

Classify repo comparison as: ALREADY_PRESENT, PARTIALLY_PRESENT, IMPLEMENTATION_ALIAS, DUPLICATE, CONTRADICTED, MISSING, GENUINELY_NEW, HISTORICAL, or CONTEXT_DEPENDENT.

## Multi-lens pressure test
Use every relevant lens, not every book mechanically:
- social/organizational cognition;
- individual cognition/cognitive load;
- judgment/uncertainty;
- human-system interaction;
- project dynamics;
- team/environment productivity;
- computational abstraction/interpreters;
- local code design;
- pragmatic engineering;
- distributed state/failure;
- computational decision policy;
- behavioral code evolution.

## Evidence standards
Prefer primary text or authoritative editions for source claims. For contested empirical claims, identify whether the source offers evidence, interpretation, metaphor or prescription and verify material claims with current research. Preserve disagreement.

## Architecture safety
Research must not create parallel truths, duplicate state machines, universal mega-graphs/services, or implementation scope solely because a source recommends a pattern. Prefer contracts, vocabulary, proof obligations, projections and extensions of existing canonical seams.

## Output hierarchy
SOURCE DOSSIER -> CROSS-SOURCE SYNTHESIS -> RESEARCH KERNEL/QUESTION -> REPO PRESSURE TEST -> CANDIDATE FINDING/CONTRADICTION/RECOMMENDATION -> CANONICAL ARCHITECTURE PROCESS.

## Anti-loss rule
A material research session is incomplete until durable artifacts contain sources introduced, principles extracted, candidate ideas, rejected/deferred ideas, unresolved questions and the next research frontier. Conversation is working memory only.
