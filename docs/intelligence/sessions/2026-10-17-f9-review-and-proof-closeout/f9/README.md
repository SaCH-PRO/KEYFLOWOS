## Findings and controls

The [hold reproduction result](results/cli-review-result.json) records execution of the actual `auto-merge-admitted.mjs --merge` CLI with the artifact's unchanged synthetic GitHub preload.

| Synthetic authority sequence | CLI exit | Snapshots | Comment-page reads | Synthetic merge PUTs |
|---|---:|---:|---:|---:|
| HOLD_SET, exact grant | 3 | 1 | 1 | 0 |
| HOLD_SET, valid HOLD_CLEAR, exact grant | 0 | 2 | 2 | 1 |
| HOLD_SET, RESUME carrying NO_STATE_CHANGE, exact grant | **0** | **2** | **2** | **1** |

For the third case, the shared envelope parser accepts the RESUME as AUTHORITY-valid, but shared `readEffect()` rejects it with `CONTROL_EFFECT_TYPE_MISMATCH: RESUME cannot carry NO_STATE_CHANGE`. The predicate at `scripts/agent-control/lib/merge-grant.mjs:229–234` nevertheless clears the hold based on the RESUME message type. The safety assertion requiring zero merge calls executed and failed (`actual: 1`, `expected: 0`). The runner's zero exit confirms this characterization and its controls; it does not indicate that the safety requirement passed.

The [pagination reproduction result](results/pagination-review-result.json) isolates the second defect. The scenario contains 150 filler comments and serializes to **174,434 bytes**. The single `KF_SYNTHETIC_GITHUB` environment entry is **174,455 bytes**, including its name and terminator. The unchanged child-launch transport returns `E2BIG`, `status: null`, and no fetch trace: the CLI never launches.

The separate [file adapter](file-scenario-preload.mjs) passes the identical JSON to the unchanged repository preload after launch. The later-page grant then executes two snapshots and four comment-page reads before one synthetic PUT. The later-page revocation executes two comment-page reads and denies with zero PUTs. These adapter results characterize the transport defect; they are not a committed correction or an original-test PASS.

## Portable source recovery and replay

Requirements: Python 3, Git, a local KEYFLOWOS repository containing the pinned artifact object, and Node. Fresh results recorded here used **Node 24.19.0 on Linux**. Node 20 was absent from the refreshed runtime; no version was installed. Separately collected Node20 hosted workflow evidence belongs to the published review and must not be attributed to these local runs.

Copy this directory into a new scratch directory before replay. The runners write their scenarios, traces, stdout, stderr, and summary JSON to `results/`; a scratch copy preserves the committed historical results. Keep the copied package's relative paths intact.

From that scratch copy, run:

```sh
python export-and-verify-source.py --repo /absolute/path/to/KEYFLOWOS
python export-and-verify-source.py --verify-only
node --version
node run-cli-review.mjs
node run-pagination-review.mjs
python export-and-verify-source.py --verify-only
```

The [source helper](export-and-verify-source.py) runs `git archive --format=tar` against the full artifact SHA and selects exactly the 30 paths listed in [source-manifest.json](source-manifest.json). It checks file length, Git blob SHA, and SHA256 for the complete archive before writing `source/`. It refuses to overwrite a nonempty destination. Verification mode reads existing bytes without modifying them. Git archive does not change the repository's current branch or working tree; the helper performs no fetch or installation. If the artifact object is absent, obtain an existing repository copy containing it before replay.

Run the [hold runner](run-cli-review.mjs) before the [pagination runner](run-pagination-review.mjs): the second intentionally reuses the first runner's emitted positive-control scenario. Both use the same unchanged source and original preload beneath `source/`. On a corrected implementation, or an operating system with a different environment limit, the characterization assertions may fail because the recorded defect no longer reproduces. Such a result requires fresh interpretation; it must not silently replace this historical record.

Those setup failures are not product findings. The incomplete auxiliary admission-suite attempt and its missing-workflow setup errors are excluded from this package; this package makes no complete local regression claim.
